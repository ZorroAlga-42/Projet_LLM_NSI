## Technologies
- Python
- Tkinter
- python-dotenv

## Description
This application is a chatbot interface for LLMs.

## Installation
1. Download this repository from GitHub.
2. Create and activate a virtual environment for this project.
3. Install the required dependencies (e.g., `python -m pip install python-dotenv`).
4. Run `PyPrompt.py`.

## Initialization
1. Complete the `.env` file with your personal information and API keys.
